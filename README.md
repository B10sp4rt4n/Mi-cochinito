## 🎯 ¿Qué es esto?

Un **simulador financiero inteligente** con **arquitectura celular fractal** que evalúa la viabilidad y rentabilidad del modelo de ahorro colectivo SIDEPE, con capacidades avanzadas de:

### Versión Tradicional
- 🤖 **Inteligencia Artificial** que analiza y recomienda (sistema de reglas)
- 🔮 **OpenAI GPT Integration** para análisis profundo (opcional)
- ✨ **Auto-optimización** de parámetros
- 📊 **Dashboard** de salud en tiempo real
- 🔄 **Simulación multi-ciclo** (3 años)
- 💬 **Chat Asistente** con GPT
- 📄 **Generador de reportes** profesionales

### 🆕 Versión Celular (NUEVO!)
- 🔬 **Células Autorreguladas**: Cada nodo se autoregula según riesgo
- 🎯 **Detección de Riesgo Multinivel**: Análisis jerárquico automático
- 🏢 **Nodos Consolidadores**: Estructura fractal que encapsula células
- 💎 **Múltiples Fuentes de Valor**: Sistema flexible e intercambiable
- 🌐 **Sistema Cerrado/Abierto**: Configuración adaptable
- 📈 **Escalabilidad Infinita**: De 1 célula a 1000+

**El simulador está VIVO** - no solo muestra números, sino que piensa, se autorregula y evoluciona.

### 🆕 Sistema de Arquitectura Celular

#### 1. 🔬 Células Autorreguladas
```python
class SavingsCell:
    ✓ Contiene múltiples fuentes de valor
    ✓ Se autorregula según métricas de riesgo
    ✓ 5 estados: ACTIVE, RECOVERING, SUSPENDED, INACTIVE, CLOSED
    ✓ Detección automática de violaciones
    ✓ Log completo de decisiones
```

**Ejemplo Real**:
```
Célula "Grupo Norte A" (50 miembros)
├── Fuente: Fondo Emergencia (5% - $2,500/mes)
├── Fuente: Núcleo Productivo (85% - $42,500/mes)
└── Fuente: Fondo Inversión (10% - $5,000/mes)

Estado: ACTIVE | Health: 87/100 | Riesgo: 23% (LOW)
```

#### 2. 🎯 Detección de Riesgo Multinivel
```
Niveles de Riesgo:
🟢 VERY_LOW (0-20%)   → Operación normal
🟡 LOW (20-40%)       → Monitoreo estándar
🟠 MEDIUM (40-60%)    → Reducción moderada de utilización
🔴 HIGH (60-80%)      → Estado RECOVERING + Reducción 20%
⚫ CRITICAL (80-100%) → Estado SUSPENDED + Reducción 50%
```

**Métricas Analizadas**:
- Default Rate (35%): Tasa de morosidad
- Volatility (20%): Variación de rendimientos
- Concentration (20%): Concentración de capital
- Liquidity (15%): Disponibilidad
- Operational (10%): Eficiencia operativa

#### 3. 🏢 Estructura Jerárquica
```
NODO MAESTRO (Sistema Completo)
  ├── CONSOLIDADOR 1 (Región/Grupo)
  │   ├── Célula A (50 miembros)
  │   ├── Célula B (30 miembros)
  │   └── Célula C (40 miembros)
  └── CONSOLIDADOR 2 (Región/Grupo)
      ├── Célula D (60 miembros)
      └── Célula E (45 miembros)
```

## 🎯 Modelo SIDEPE

Sistema de ahorro con **triple fondo**:

| Fondo | % | Función |
|-------|---|---------|
| **FEE** | 5-10% | Estabilidad - Colchón de emergencias |
| **Núcleo** | 80-90% | Capital productivo - Genera rendimientos |
| **FIC** | 5-10% | Inversión conservadora - Diversificación |

**Rendimientos objetivo:**
- Núcleo: 42.6% anual (préstamos)
- FIC: 14% anual (inversiones)
- **ROI global: 20-30%**
